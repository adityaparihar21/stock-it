stock-it Product Inventory REST API

Powered by Express.js, Mongoose & MongoDB

Available Endpoints

  • GET /products
  • GET /products/stats
  • GET /products/:id
  • POST /products
  • PUT /products/:id
  • DELETE /products/:id

Database Schema

MongoDB Collection: product_inventory.products

  • name: String (Required)
  • brand: String (Required)
  • category: String (Required)
  • price: Number (Required, Min: 0)
  • stock: Integer (Required, Min: 0)
  • description: String (Optional)
  • imageUrl: String (Optional)
